# Despensa Organizada

Aplicativo Android para ajudar a organizar os produtos da casa. Com ele, é possível acompanhar o estoque, os locais onde os itens foram guardados, as datas de validade e as movimentações de entrada e retirada.

## Funcionalidades

- Cadastro, consulta, edição de produtos.
- Leitura de código de barras durante o cadastro e a busca de produtos.
- Registro de entradas e retiradas, com quantidade, local de armazenamento e validade.
- Consulta do estoque atual e do histórico de movimentações.
- Lista de compras com produtos que precisam de reposição.
- Consulta de vencimentos e relatório de gastos.(ainda indisponivel)

## Tecnologias

- Kotlin
- Android SDK (compile SDK 35; versão mínima Android 6.0/API 23)
- SQLite para armazenamento local
- Google Play Services Code Scanner para leitura de códigos de barras
